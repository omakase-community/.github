# Omakase profile artwork

The current cover and avatar adapt the approved laptop cat from the Omakase landing page using the built-in image generation tool. Original PNG outputs are retained locally; the cover and upload avatar are JPEG conversions at quality 88. The older house-cat assets remain for history.

Working palette: cream `#f4eddf`, indigo `#283c68`, forest `#244b3e`, with the existing small persimmon laptop sticker.

## Cover prompt

Create a polished wide GitHub organization profile cover for Omakase. Asset type brand banner, aspect ratio 3:1. Reference image is the approved Omakase hacker cat: preserve its exact character identity, forest green bandana, mischievous confident expression, indigo fur, laptop with tiny persimmon lightning sticker, risograph grain and cream paper. Place this recognizable sitting laptop cat on the right third of a warm cream #f4eddf field with ample breathing room and no surrounding frame. Left half: exact single word 'Omakase' in very bold Archivo Black-like rounded heavy sans serif, indigo #283c68, large clean readable typesetting. No other text, no slogans, no badges, no additional logos, no trees. Palette limited to warm cream, indigo, forest #244b3e, tiny existing persimmon sticker. Understated print studio look matching the reference, subtly textured not dirty. Keep cat fully inside canvas, do not crop ears or laptop. Flat artwork, not a device mockup. This is a faithful brand adaptation of existing art, not a new cat design.

## Avatar prompt

Create a square GitHub organization avatar adapting this exact approved Omakase cat. Preserve the cat identity and mischievous confident expression, indigo ink fur, forest green tied bandana, warm cream face, risograph print grain. Head and upper shoulders only, centered on plain warm cream #f4eddf background. No laptop, no table, no text, no border, no frame, no badge. Both ears and bandana knot fully visible with 12% breathing room around the silhouette for circular avatar cropping. The face must read clearly at 40px. Same cat as reference, not a new character. Tight coherent silhouette; strong indigo #283c68 outlines and forest #244b3e bandana. Output one finished square image.
